# Legal review checklist — before launch

> The in-app documents are DRAFT scaffolds (`is_draft=true`). Do NOT present them as final until
> each item below is signed off. This checklist does not itself constitute compliance.

- [ ] Privacy Policy reviewed & finalised (remove DRAFT banner, set `is_draft=false`, bump version)
- [ ] Terms of Service reviewed & finalised
- [ ] Parent/Carer Terms reviewed
- [ ] School Terms + Data Processing Agreement drafted with counsel
- [ ] Acceptable Use Policy reviewed
- [ ] Child Safety / Safeguarding statement reviewed by DSL
- [ ] Cookie Policy matches actual cookies set
- [ ] Refund/Cancellation Policy matches billing implementation + UK consumer law
- [ ] AI Use & Limitations notice reviewed
- [ ] Accessibility statement reflects real WCAG status
- [ ] DPIA completed and DPO sign-off obtained
- [ ] Processing register + processor DPAs verified
- [ ] Retention periods confirmed and automated where possible
- [ ] DSAR workflow tested (access/export/deletion/correction/objection)
- [ ] Re-consent flow verified when a document version changes
- [ ] ICO registration / fee status confirmed
